Gata & Appa (GatOS Components)

Planned

Gata and Appa are two complementary components to GatOS. Gata is a custom high-level programming language for writing operating systems, which will be used by programmers to simplify OS Dev. Appa is the compiler for Gata. It will take in Gata source code and transpile it into C code that calls GatOS's APIs. Appa will construct the kernel depending on the code's logic by leveraging the modularity of GatOS's design.
